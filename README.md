## 代码说明

`code/pwm_led/` 是 PWM 呼吸灯，用标准外设库（SPL），运行在 STM32F103C8T6。

- TIM2 通道 1 → PA0，复用推挽输出
- PSC = 719，ARR = 99 → 频率 1 kHz
- CCR 从 0 到 100 再回 0，实现亮度渐变

**一个已知的命名问题**：`LED.c` 里的函数叫 `LED_Init`，但实际内容是 PWM 初始化。这是从点灯阶段一路改过来的历史遗留，后续会重命名为 `PWM_Init` 并拆到独立文件。
